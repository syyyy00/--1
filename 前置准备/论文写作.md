
## 任务一：学习“摘要”的写作套路

### 为什么摘要最重要？

摘要占全文得分的至少30%。评委阅读一篇论文的时间通常不到10分钟，摘要更是只有1-2分钟。摘要好，评委才会认真看正文；摘要差，正文写得再好也可能被埋没。

### 摘要应该包含哪些内容？

根据多篇获奖论文的总结，摘要需要覆盖以下五个核心要素：

| 要素 | 具体内容 | 篇幅 |
|------|---------|------|
| 问题概述 | 本文研究了什么问题，问题背景和现实意义 | 1-2句 |
| 建模思路 | 针对每个问题建立了什么模型（核心方法） | 3-5句 |
| 求解方法 | 用了什么算法、工具求解 | 2-3句 |
| 主要结果 | 核心量化结果（具体数值！） | 3-5句 |
| 结论与亮点 | 模型优势、创新点、检验结果 | 1-2句 |

### 摘要写作的核心套路

**关键原则：摘要中必须出现具体的数值结果**，不能只写“结果较好”“效果显著”。量化才是得分关键。

以下是一套可以直接套用的摘要写作模板：

> **摘要**
>
> 本文研究了[问题背景，一句话概括]。
>
> 针对问题一（[具体问题]），本文建立了[模型名称]模型。该模型将[什么因素]作为决策变量，以[什么]为目标函数，考虑了[哪些约束条件]。
>
> 针对问题二（[具体问题]），本文在问题一的基础上，进一步引入了[什么因素/机制]，建立了[模型名称]模型。
>
> 在模型求解方面，本文采用[方法名称]算法进行求解，借助[工具名称]编程实现。求解结果表明：[具体数值结果一，比如“系统总成本降低了XX%”]；[具体数值结果二]。
>
> 为进一步验证模型的可靠性，本文进行了[灵敏度分析/稳定性检验]，结果表明模型对[某参数]的变化具有较好的鲁棒性。此外，还将模型结果与[基准方法/文献结果]进行了对比，本文模型的[某指标]优于对比方法XX%。
>
> 本文模型的优点在于：[1-2个核心优点]。模型可推广应用于[某实际场景]。
>
> **关键词**：[4-6个关键词，涵盖问题领域、核心方法、主要工具]

### O奖论文摘要的典型特征

高水平的摘要不仅仅是信息齐全，还具备以下特征：
- **一句话能讲清“做了什么、怎么做的、结果如何”**
- **每个方法后面都跟着对应的数值结果**
- **语言高度凝练，没有废话，信息密度极高**
- **可独立作为一篇微型研究报告阅读**

### 具体动作

1. 找3-5篇电工杯一等奖论文，只看它们的摘要，逐句标注每句话属于上面五个要素中的哪一个。
2. 对照上述模板，试着给一篇往届真题写一个模拟摘要，要求每句话都带信息量。
3. 比赛时，写完初稿后至少打磨三遍以上，砍掉所有空话。

**产出**：你的“摘要自查清单”——每写完一版摘要，对照清单检查是否五个要素齐全、每句是否有具体数值。


## 任务二：拆解论文结构，搭建写作框架

### 标准论文结构一览

数学建模竞赛论文有非常固定的结构模板，根据多家竞赛的格式规范，标准结构如下：

| 章节 | 核心内容 | 写作要点 |
|------|---------|---------|
| **摘要** | 全文精华浓缩 | 独立成页，300-500字，含具体数值 |
| **一、问题重述** | 用自己的话重新表述题目 | 不能照抄题目原文，要体现理解深度 |
| **二、问题分析** | 拆解题意，说明解题思路 | 每个小问对应什么模型/方法，为什么 |
| **三、模型假设与符号说明** | 假设+合理性解释+符号表 | 假设必须与建模有关，符号统一用表格呈现 |
| **四、模型建立与求解** | 核心！公式推导+算法设计+求解结果 | 按小问分节，每节含“分析→公式→求解→结果” |
| **五、模型检验与分析** | 误差分析+灵敏度分析+稳定性检验 | 图表展示，有对比基准 |
| **六、模型评价与改进** | 优点+缺点+推广方向 | 客观、具体、可操作 |
| **参考文献** | 列出引用的文献 | 5-10篇，格式统一 |
| **附录** | 核心代码、补充数据 | 代码要有注释 |

### 篇幅分配参考

正文控制在20页左右是国赛公认的最佳篇幅。一个行之有效的比例是“5-10-5”：

- **前5页**：问题背景、符号定义、数据说明、总体思路
- **中间10页**：建模、算法、实验与结果展示（全文核心）
- **后5页**：灵敏度分析、误差检验、结论与反思

在这个篇幅范围内，推荐配置为：图10-12个、表6-8个较为合适。

### 具体动作

1. 找一篇电工杯一等奖论文，对照上表把每一章的小标题和核心内容摘抄下来，做成结构笔记。
2. 观察这篇论文的段落划分——每个模型小节里，作者先写什么、后写什么？用一两句话概括“行文逻辑链条”。
3. 自己用Word或LaTeX搭建一个空白论文框架（只有章节标题和分页），比赛时直接往里填充内容。

**产出**：你自己的“论文结构模板文件”（Word或LaTeX），包含所有章节标题和预置的空白图表占位符。


## 任务三：学会“假设”和“符号”的专业写法

### 模型假设怎么写才合理？

模型假设是评委评判论文严谨性的第一道关口。常见问题是“假设太大太空”或“假设没有合理解释”。

**假设写作的三条核心原则**：

1. **必须用严格、确切的数学语言表达**，不能让读者产生任何曲解。
2. **所提出的假设必须与建模直接相关**，与模型无关的假设只会扰乱评委思路。
3. **每条假设都要给出合理性解释**，不能凭空捏造。

**假设合理性的三种论证方式**：
- 从问题的性质出发，做出合乎常识的推断
- 通过观察给定数据的图像，得出变量的函数形式
- 引用参考文献来支持假设的合理性

**常见的假设类型与范例**：

| 假设类型 | 典型写法 | 合理性解释 |
|---------|---------|-----------|
| 排除小概率事件 | “假设在研究期间不发生经济危机、系统故障等极端事件” | 小概率事件不属于常态分析范围 |
| 仅考虑核心因素 | “假设交通拥堵仅考虑机动车的影响，忽略非机动车与行人” | 题目数据以机动车为主，非机动车影响量级较小 |
| 模型固有假设 | “假设博弈参与者均为理性人，追求自身利益最大化” | 该假设是博弈论模型的标准前提 |
| 参数形式假设 | “假设人口增长服从阻滞增长模型（Logistic模型）” | 已有文献表明该模型能较好拟合历史数据 |
| 分布假设 | “假设单位时间内到达的顾客数服从泊松分布” | 通过实际数据绘制Q-Q图验证了该假设 |

**写作格式建议**：
> **3.1 模型假设**
>
> （1）假设[具体内容]。理由：[简短的合理性解释]。
>
> （2）假设[具体内容]。理由：[简短的合理性解释]。

**关于假设强弱度的平衡**：假设太强，模型过于简单，论文没有深度和亮点；假设太弱，模型过于复杂，可能无法求解。如果确实需要做较强假设来简化问题，可以在“模型评价与改进”部分说明放宽该假设的改进方向。

### 符号说明怎么写得清晰？

用**三线表**格式呈现，包含四列：符号、含义、单位、备注。

| 符号 | 含义 | 单位 | 备注 |
|------|------|------|------|
| \(P_{wt}(t)\) | t时刻风电出力 | MW | 决策变量 |
| \(C_{bat}\) | 储能系统投资成本 | 万元/MWh | 已知参数 |
| \(\eta_{ch}\) | 充电效率 | — | 取0.95 |

**要点**：同一符号全文统一；下标规则一致（如 \(t\) 表示时段、\(i\) 表示节点）；符号尽量简洁但不失可读性。

### 具体动作

1. 看一篇电工杯一等奖论文，找出它的“模型假设”章节，逐条分析每条假设属于哪种类型、作者是怎么解释合理性的。
2. 看这篇论文的符号说明表，关注“下标规则”——作者是怎么用下标区分不同对象和时段的。
3. 尝试针对某一届电工杯真题，自己写出5-8条假设及其合理性解释。

**产出**：假设写作的三类模板（排除型/简化型/模型固有型），每种储备一个典型范例；符号说明表模板。


## 任务四：掌握图表可视化规范

### 图表是论文的“门面”

在数学建模竞赛中，图表是评委快速理解你模型和结果的直观方式。优秀的图表能让论文质量提升一个档次，糟糕的图表则会让好模型大打折扣。

### 图表的三大基本要求

**（1）清晰性：3秒原则**

评委阅读一张图通常不超过3秒，图表必须让读者在3秒内抓住核心信息。具体做到：
- 避免信息过载：一张图只讲一个故事
- 标签和图例必须完整：坐标轴标签、单位、图例缺一不可
- 图注（Caption）应**独立于正文**，完整描述图表内容和核心结论

**（2）专业性：细节决定成败**

图表中的所有文字（坐标轴标签、图例、图注）应与正文的英文字体（Times New Roman）保持一致，字号适中（通常比正文小1-2号）。务必使用矢量图格式（PDF、EPS或SVG），保证放大不失真。配色上，避免使用过于鲜艳或默认的“彩虹色”，推荐使用灰度、单色系渐变或科研论文常用配色方案（如Nature、Science风格），保持图表整体的沉稳和高级感。

**（3）一致性：全文视觉风格统一**

整篇论文的所有图表必须在视觉风格上保持高度统一：
- 线条粗细一致
- 颜色映射一致（如红色代表“高风险”，全文保持这一含义）
- 图表编号规范（严格按“图1”“图2”格式）

### 图表的具体规范

| 规范项 | 具体要求 |
|--------|---------|
| 编号方式 | 图、表分开编号：“图1”“表1” |
| 题注位置 | 图的题注在下方，表的题注在上方 |
| 引用方式 | 正文中用“见图3”“如表2”，不写“如下图”“如下表” |
| 表格格式 | 推荐使用三线表（booktabs风格） |
| 分辨率 | 所有图片清晰度≥300dpi |
| 编号管理 | Word用“插入题注”“交叉引用”功能，禁止手打编号 |

### 常用图表类型选择指南

| 你要展示什么 | 推荐的图表类型 |
|-------------|--------------|
| 时间序列趋势 | 折线图 |
| 不同方案的数值对比 | 柱状图 / 条形图 |
| 占比关系 | 饼图 / 堆叠柱状图 |
| 两变量关系 | 散点图 + 拟合曲线 |
| 多变量相关性 | 热力图 |
| 空间分布 | GIS地图 / 热力图 |
| 算法流程 | 流程图 |
| 模型结构 | 结构框图 |
| 网络关系 | 网络图 / 关系图 |
| 数据分布与离群值 | 箱线图 / 小提琴图 + 散点图组合 |

### 图表标题的写法

差的标题：“图1 结果图”（信息量为零）
好的标题：“图1 不同储能配置方案下的系统日运行成本对比（场景A：风电渗透率30%）”（一张图讲清全部信息）

### 具体动作

1. 对照上面的规范清单，逐一检查你之前画过的图，找出3个可以改进的细节。
2. 重点练习两种图：**多方案对比的柱状图**和**灵敏度分析的折线图**，这是建模论文出镜率最高的两类图。
3. 学习使用学术风格的配色方案。如果你用Python画图，搜索“matplotlib学术配色”或`seaborn`的`color_palette`；如果用MATLAB，避免使用默认的高饱和度颜色。

**产出**：你的“绘图代码模板库”——至少包含折线图、柱状图、散点图、热力图四种基本图的脚本，比赛时直接套参数即可。


## 电工杯论文的特殊注意事项

电工杯的题目具有鲜明的行业特色，论文写作时需要注意以下几个方面：

- **A题（机理驱动型）** 评委看重“物理规则的严谨性”。务必在论文中明确写出基于基尔霍夫定律、能量守恒等物理约束，不能只堆算法没有物理背景。
- **B题（数据驱动型）** 评委极度厌恶“盲目套用评价模型”（如毫无道理地用AHP+TOPSIS）。关键在于：为什么要用这个方法？指标体系怎么构建的？必须给出合理推导过程。
- **无论是A题还是B题，结果的可视化都特别重要**。电网拓扑图、负荷曲线、风光出力对比图、收敛曲线等如果能画出高质量版本，对评分帮助极大。
