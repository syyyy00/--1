## 1. 优化类问题

**问题特征**：在一定约束条件下，求某个目标（成本、效率、距离）的最大值或最小值。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **线性规划** | 目标与约束均为线性。如：运输调度、生产计划、电源出力分配（经济调度）。 | `from scipy.optimize import linprog`<br>`res = linprog(c, A_ub, b_ub, A_eq, b_eq, bounds)` |
| **整数/混合整数规划** | 决策变量有整数限制（人数、设备台数、开/关状态）。如：机组启停、选址问题。 | `import pulp`<br>`prob = pulp.LpProblem()`<br>`x = pulp.LpVariable.dicts("x", range(n), cat='Integer')`<br>`prob.solve()` |
| **非线性规划** | 目标或约束含非线性函数。如：参数拟合、最优潮流、考虑网损的经济调度。 | `from scipy.optimize import minimize`<br>`res = minimize(fun, x0, constraints=cons, bounds=bounds)` |
| **动态规划** | 多阶段决策，每阶段决策影响下一阶段。如：水库调度、储能充放电策略。 | 需手动构建状态转移方程和价值函数，无通用单函数，常用字典或数组迭代。 |
| **遗传/粒子群等智能算法** | 问题特别复杂、非凸、导数难求。如：复杂的电网规划、多目标优化。 | `from sko.GA import GA`<br>`ga = GA(func, n_dim, ...)`<br>`best_x, best_y = ga.run()` |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **多目标优化（转化为单目标）** | 同时优化成本、排放等多个冲突目标。如：经济-环保双重调度。 | 线性加权：`def obj(x): return w1*f1(x) + w2*f2(x)`，然后用 `minimize`；或使用 `pymoo` 库进行帕累托寻优。 |
| **最小费用最大流** | 在保证流量最大的前提下，找总费用最小的方案。如：电力市场输电路径分配。 | `import networkx as nx`<br>`mincostFlow = nx.min_cost_flow(G)`<br>需设置边的容量、费用，及节点供需。 |
| **模拟退火 / 蚁群算法** | 离散组合优化，如 TSP、机组组合。 | `from sko.SA import SA`<br>`sa = SA(func, x0, T_max=100, ...)`<br>`best_x, best_y = sa.run()` |

## 2. 微分方程与机理建模

**问题特征**：系统状态随时间或空间连续变化，由物理定律支配，如电流、温度、速度变化。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **常微分方程(ODE)初值问题** | 已知变化率和初始状态，求后续状态。如：电机转速变化、RC 电路充放电、传染病 SIR 模型。 | `from scipy.integrate import solve_ivp`<br>`sol = solve_ivp(dydt, [t0, tf], y0, t_eval=np.linspace(...))` |
| **偏微分方程(PDE)** | 状态同时随时间和空间变化。如：电缆温度分布、散热器导热。 | `import py-pde` 或 `from FiPy import ...`<br>需定义网格、方程和边界条件，通常手动编写差分格式。 |
| **差分方程** | 离散时间系统状态变化。如：离散控制系统、递推预测模型、人口迭代模型。 | 用循环实现：`for t in range(T): x[t+1] = f(x[t], u[t])` |
| **参数辨识** | 已知系统微分方程结构，从数据反推未知参数。如：根据电机响应曲线，辨识转动惯量和阻尼系数。 | 结合 `solve_ivp` 与 `minimize`：定义以参数为变量的误差函数，用非线性最小二乘优化。<br>`res = minimize(error_func, param_guess)` |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **PDE 有限差分法（自编程）** | 导热、电磁场、电缆温度分布等。 | 用 `numpy` 构建网格，迭代求解。如热方程：<br>`u[1:-1] = u[1:-1] + dt*k/dx**2 * (u[2:] - 2*u[1:-1] + u[:-2])` |
| **非线性代数方程组求解** | 电力系统潮流计算（功率平衡方程）、稳态电路方程。 | `from scipy.optimize import fsolve`<br>`sol = fsolve(equations, x0)`<br>可用于牛顿-拉夫逊法的简单实现。 |

## 3. 统计回归与预测（传统模型）

**问题特征**：从大量数据中找出变量间的相关关系或对未来进行点预测。数据量不大，重视关系可解释性。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **线性/多项式回归** | 自变量与因变量呈明显线性/曲线关系。如：电力负荷与温度的线性关系、成本拟合。 | `from sklearn.linear_model import LinearRegression`<br>`model = LinearRegression().fit(X, y)`<br>`y_pred = model.predict(X_new)` |
| **逻辑回归** | **二分类**问题。如：故障诊断（正常/故障）、用户购买意愿（是/否）。 | `from sklearn.linear_model import LogisticRegression`<br>`model = LogisticRegression().fit(X, y)`<br>`y_prob = model.predict_proba(X)` |
| **灰色预测 GM(1,1)** | 数据量极少(4-10 个)、呈指数趋势。如：年用电量长期预测、设备寿命预估。 | 核心是累加生成和微分方程，可自写函数或 `from py-grey import GreyModel` |
| **时间序列 ARIMA** | 数据有明显的随时间变化的周期/趋势，且平稳。如：短期日负荷预测、风速预测。 | `from statsmodels.tsa.arima.model import ARIMA`<br>`model = ARIMA(series, order=(p, d, q))`<br>`model_fit = model.fit()`<br>`forecast = model_fit.forecast(steps)` |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **岭回归 / Lasso 回归** | 数据有多重共线性或需要特征选择时。如：从众多气象因素中选负荷敏感因子。 | `from sklearn.linear_model import Ridge, Lasso`<br>`model = Ridge(alpha=1.0).fit(X, y)` |
| **指数平滑法(Holt-Winters)** | 具有趋势和季节性的时间序列短期预测。如：日负荷曲线的周期波动。 | `from statsmodels.tsa.holtwinters import ExponentialSmoothing`<br>`model = ExponentialSmoothing(train, seasonal='add', seasonal_periods=24).fit()` |
| **XGBoost / LightGBM** | 结构化数据的回归和分类，精度通常高于随机森林，电工杯预测题优选。 | `import xgboost as xgb`<br>`model = xgb.XGBRegressor(n_estimators=100).fit(X, y)` |
| **皮尔逊/斯皮尔曼相关系数** | 分析变量间线性或单调关系，快速筛选建模特征。 | `from scipy.stats import pearsonr, spearmanr`<br>`r, p = pearsonr(x, y)` |

## 4. 评价决策类问题

**问题特征**：对多个对象从多个指标进行综合评价、排序或选择最优。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **层次分析法(AHP)** | 指标不多(≤9)，需通过专家两两比较确定权重。如：电网建设项目方案评选、供应商选择。 | 构建判断矩阵，手动计算特征向量。核心代码：<br>`np.linalg.eig(A)` 取最大特征值对应的特征向量归一化。 |
| **TOPSIS 法** | 基于数据本身分布，客观评价。找出离理想解最近、离负理想解最远的方案。如：各省电网发展水平评价。 | 本质是矩阵运算。先对数据正向化、标准化，再计算欧式距离：<br>`D_pos = np.sqrt(((Z - Z_max)**2).sum(axis=1))` |
| **熵权法** | 完全根据数据变异性客观确定权重，常与 TOPSIS 组合使用。 | 计算各指标信息熵 `E_j`，权重 `w_j = (1-E_j) / sum(1-E)` |
| **模糊综合评价** | 评价存在模糊性、难以精确量化。如："供电可靠性"的评价（好、较好、一般）。 | 需自建隶属度函数，常用梯形/三角形函数，再与权重向量进行模糊合成。 |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **数据包络分析(DEA)** | 多投入多产出单位的相对效率评价。如：不同地区电网的运营效率。 | 本质是线性规划，可用 `pulp` 或 `pydea` 包：<br>`from pydea import DEA`<br>`dea = DEA(inputs, outputs)`<br>`eff = dea.efficiency()` |
| **灰色关联分析** | 数据少、分布未知，想判断哪个因素对目标影响最大。 | 需自编公式：先无量纲化，计算关联系数，再求关联度。核心是双重循环比较序列与参考序列的绝对差。 |
| **CRITIC / 变异系数法** | 客观赋权，考虑指标冲突性和变异性，比熵权法更全面。 | 计算标准差和相关系数矩阵：<br>`std = np.std(X, axis=0)` 和 `corr = np.corrcoef(X.T)`，权重为 `std * (1 - corr).sum(axis=1)` 后归一化。 |

## 5. 图论与网络问题

**问题特征**：研究对象由节点和连接节点的边构成，如电网、交通网、通信网。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **最短路问题** | 寻找两点间最短路径（距离、成本、时间）。如：输电路径规划、物资配送。 | `import networkx as nx`<br>`G = nx.Graph()`<br>`path = nx.shortest_path(G, source, target, weight='cost')` |
| **最小生成树** | 用最少的"边"连接所有节点。如：局域网布线、配电网辐射状规划。 | `T = nx.minimum_spanning_tree(G)` |
| **最大流问题** | 在网络容量限制下，求从源点到汇点的最大流量。如：天然气管道输送能力分析、电流极限分析。 | `from networkx.algorithms.flow import maximum_flow`<br>`flow_value, flow_dict = maximum_flow(G, s, t)` |
| **旅行商问题(TSP)** | 遍历所有点且仅一次，回到起点，路径最短。如：巡检无人机路径规划。 | 小规模可用动态规划或<br>`from python_tsp.heuristics import solve_tsp_simulated_annealing` |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **二分图最大匹配** | 资源配置中一方对一方的唯一匹配。如：充电桩与待充电车辆的分配。 | `from networkx.algorithms.bipartite import maximum_matching`<br>`matching = maximum_matching(B, top_nodes)` |
| **连通度 / 网络攻击模拟** | 评估电网关键线路识别，看移除某节点/边后网络最大连通子团大小。 | `G.remove_node(node)`<br>`components = nx.connected_components(G)`<br>`largest = max(components, key=len)` |

## 6. 机器学习类问题

**问题特征**：数据量大，关系高度非线性，重在预测精度，弱化物理可解释性。电工杯中常用于负荷预测、故障诊断。

### 核心模型

| 模型/算法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **K-近邻(KNN)** | 小数据量下简单的分类或回归基线模型。如：基于历史相似日的负荷预测。 | `from sklearn.neighbors import KNeighborsRegressor`<br>`model = KNeighborsRegressor(n_neighbors=5).fit(X, y)` |
| **支持向量机(SVM)** | 小样本、非线性、高维模式识别。如：变压器故障分类。 | `from sklearn.svm import SVC`<br>`model = SVC(kernel='rbf').fit(X, y)` |
| **决策树/随机森林** | 特征重要度分析、抗噪声能力强。如：电力系统暂态稳定评估、用户分类。 | `from sklearn.ensemble import RandomForestClassifier`<br>`model = RandomForestClassifier().fit(X, y)`<br>`importances = model.feature_importances_` |
| **神经网络/长短时记忆网络(LSTM)** | 处理极复杂关系或时间序列。如：超短期负荷预测、新能源出力预测。 | `from tensorflow.keras.models import Sequential`<br>`from tensorflow.keras.layers import LSTM, Dense`<br>需构建序列模型、编译、训练。 |

### 扩展模型

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **K-Means 聚类** | 无标签数据分组。如：用电客户画像、负荷曲线聚类。 | `from sklearn.cluster import KMeans`<br>`kmeans = KMeans(n_clusters=3).fit(X)`<br>`labels = kmeans.labels_` |
| **高斯朴素贝叶斯** | 概率分类，样本少时快速建模。如：基于历史数据的简单故障分类。 | `from sklearn.naive_bayes import GaussianNB`<br>`gnb = GaussianNB().fit(X, y)` |
| **孤立森林** | 离群点/异常数据检测。如：识别电表采集数据中的坏值。 | `from sklearn.ensemble import IsolationForest`<br>`clf = IsolationForest(contamination=0.01).fit(X)`<br>`y_pred = clf.predict(X)` |

## 7. 数据预处理与分析方法

> ⚠ **说明**：以下方法不属于"模型"，而是建模流程中必不可少的辅助工具，在此集中整理以便速查。

| 方法 | 目的 | 核心代码 |
| :--- | :--- | :--- |
| **数据标准化/归一化** | 消除量纲影响，使各特征处于同一数量级。 | `from sklearn.preprocessing import StandardScaler`<br>`scaler = StandardScaler().fit(X)`<br>`X_scaled = scaler.transform(X)` |
| **主成分分析(PCA)** | 降维，提取主要特征，用于可视化或去噪。 | `from sklearn.decomposition import PCA`<br>`pca = PCA(n_components=2).fit(X)`<br>`X_pca = pca.transform(X)` |
| **插值法** | 补全缺失数据或加密数据。如：缺失的负荷数据补全。 | `from scipy.interpolate import interp1d`<br>`f = interp1d(x, y, kind='cubic')`<br>`y_new = f(x_new)` |

## 8. 随机模拟与专业场景

**问题特征**：涉及随机性、排队系统分析，或特定领域的专业计算（如电力系统）。

| 模型/方法 | 适用场景 | Python 调用代码模板 |
| :--- | :--- | :--- |
| **蒙特卡洛模拟** | 处理不确定性问题，通过大量随机试验估计结果。如：新能源出力的概率潮流计算、可靠性评估。 | 用 `np.random` 生成大量样本，重复计算模型，统计结果的均值/分位数。<br>`samples = np.random.normal(mu, sigma, (n, N))` |
| **排队论（M/M/c 等）** | 分析服务系统效率。如：充电站等待时间、呼叫中心排队。 | 可自写公式或用 `ciw` 库：`import ciw` 定义网络，模拟。 |
| **潮流计算（牛顿-拉夫逊法）** | 给定电力网络结构和注入功率，求解各节点电压。电工杯核心专业模型。 | 推荐用 `pandapower`：<br>`import pandapower as pp`<br>`net = pp.create_empty_network()`<br>`pp.runpp(net)`<br>或用 `matpower` 的 Python 接口。 |
| **状态估计** | 由含有噪声的量测数据估计电网最可能运行状态。 | 通常用加权最小二乘法，`WLS = minimize(sum(w_i * (z_i - h_i(x))^2))`，可利用 `pandapower.estimation`。 |

│ y 为连续数值 (回归)  │   │ y 为离散类别 (分类)      │
└──────────┬──────────┘   └────────────┬────────────┘
           ▼                           ▼
┌──────────────────────┐  ┌──────────────────────────┐

├──────────────────────┤  ├──────────────────────────┤
│ 数据量中等 / 可解释性 │  │ 多分类 / 小样本           │

├──────────────────────┤  ├──────────────────────────┤
│ 数据量大 / 精度优先   │  │ 精度优先 / 特征重要性     │

├──────────────────────┤  ├──────────────────────────┤

│   Winters[3]         │  │                          │
